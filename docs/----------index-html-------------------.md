## 📁 `public/index.html` — هيكل الآلة الحاسبة

### 🖥️ شاشة العرض (Display)
| العنصر | الوصف |
|--------|-------|
| `#expression` | يعرض التعبير الحسابي الكامل (مثال: `5 × 3 =`) |
| `#result` | يعرض الرقم الحالي أو النتيجة النهائية |

### 🔢 أزرار الأرقام (0-9)
- الأرقام `1–9` كل واحد في خلية مستقلة
- الزر `0` يمتد على خليتين (`grid-column: span 2`)

### ⚙️ أزرار العمليات
| الزر | العملية |
|------|---------|
| `÷` | القسمة (`/`) |
| `×` | الضرب (`*`) |
| `−` | الطرح (`-`) |
| `+` | الجمع |
| `%` | النسبة المئوية |

### 🎯 أزرار التحكم
| الزر | الوظيفة |
|------|---------|
| `C` | مسح الكل (Clear) |
| `⌫` | حذف آخر رقم (Delete) |
| `.` | الفاصلة العشرية |
| `=` | حساب النتيجة (يمتد على خليتين) |

### ✨ مزايا إضافية موجودة
- **لوحة المفاتيح**: دعم كامل (`0-9`, `+`, `-`, `*`, `/`, `Enter`, `Backspace`, `Escape`)
- **RTL**: اتجاه عربي كامل (`lang="ar" dir="rtl"`)
- **Responsive**: تصميم متجاوب للشاشات الصغيرة
- **Accessibility**: `aria-label` على كل زر + `aria-live` على الشاشة
- **حماية القسمة على صفر**: تعرض "خطأ" بدلاً من `Infinity`
- **Chaining**: يمكن تسلسل العمليات (`5 + 3 × 2`)
