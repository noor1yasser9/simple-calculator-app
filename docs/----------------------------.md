## ملخص التغييرات

### 🐛 Bug مُصلَح — `clearEntry()` عند `waitingForOperand`

**المشكلة:** ضغط `C` بعد اختيار عملية (مثل `5 +`) كان لا يفعل شيئاً.  
**الإصلاح:** الآن يُلغي العملية المعلّقة ويعود للقيمة السابقة:
```
5 + → اضغط C → يعود لـ "5" مع إلغاء "+"
```

---

### ✨ ميزات جديدة

| الملف | التغيير |
|-------|---------|
| **`calculatorStore.ts`** | إضافة `errorType: 'overflow'` للأرقام الكبيرة جداً |
| **`calculatorStore.ts`** | إضافة `errorCount: number` — يزيد +1 مع كل خطأ جديد |
| **`tailwind.config.ts`** | إضافة `animate-shake` — حركة اهتزاز أفقية متدرجة `0.4s` |

| **`Display.tsx`** | رسالة جديدة: `'overflow' → "الرقم كبير جداً"` |
| **`CalcButton.tsx`** | Variant جديد `error-clear` — أحمر شفاف مع hover |
| **`Calculator.tsx`** | زر AC/C يتحوّل لـ `error-clear` عند وجود خطأ لإرشاد المستخدم |

### 🎨 UX — رحلة المستخدم عند الخطأ

```
القسمة على صفر (5 ÷ 0 =)
    ↓
الشاشة تهتز (animate-shake)
الشاشة تتحول للأحمر + "لا يمكن القسمة على صفر"
زر AC/C يتحوّل للأحمر (error-clear variant)
كل الأزرار معطّلة ما عدا AC/C
    ↓
المستخدم يضغط AC/C → مسح كامل والبدء من جديد
```
