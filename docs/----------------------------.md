### 🧠 المنطق المُطبَّق

#### 1. تراكم الأرقام على الشاشة (`inputDigit`)
```
"4" → "4"    "4" + "2" → "42"    "42" + "5" → "425"
```
- `isNewInput = true` (بعد عملية أو نتيجة) → **يستبدل** بدل التراكم
- الرقم الحالي `"0"` → يُستبدل بالرقم الجديد (لا "07")
- حماية من overflow عند `MAX_DIGIT_LENGTH = 15`

#### 2. حفظ العملية الحسابية (`selectOperator`)
```
42 → [+] → { previousInput: "42", operator: "+", isNewInput: true }
```
- **تصحيح العملية:** ضغط عملية أخرى قبل إدخال رقم → يُحدِّث العملية فقط
- **حساب متسلسل:** `3 + 2 [*]` → يُنفِّذ `3+2=5` ثم يحفظ `*`
