## ✅ ملخص التغييرات

### 📁 `src/lib/calculatorStore.ts`

| التغيير | التفاصيل |
|---------|----------|
| **نوع جديد `ErrorType`** | `'division-by-zero' \| 'invalid-input' \| null` — يُميّز بدقة بين القسمة على صفر وغيرها |
| **حقل `errorType` في الحالة** | مُضاف إلى `CalculatorState` و`INITIAL_STATE` |
| **`applyOperator` محسّن** | يُعيد `OperationResult` مكتوب بـ discriminated union بدلاً من `string \| null` |
| **`errorSnapshot(errorType)`** | دالة مساعدة تُصفّر كامل الحالة عند الخطأ (تضمن عدم وجود حالات غير متسقة في كل مسار) |
| **`clearEntry()` ذكي** | **في حالة خطأ → إعادة ضبط كاملة (AC)**؛ **في حالة انتظار معامل → لا فعل**؛ **عادي → يمسح الإدخال الحالي فقط** |
| **`formatResult()` محدّث** | يُعيد `null` بدلاً من `'Error'` — يُتيح للـ Store التحكم الكامل في حالة الخطأ |

### 📁 `src/components/calculator/Display.tsx`

| التغيير | التفاصيل |
|---------|----------|
| **`errorType` prop** | يستقبل نوع الخطأ من الـ Hook |
| **`ERROR_MESSAGES` map** | `division-by-zero` → `"لا يمكن القسمة على صفر"` / `invalid-input` → `"خطأ في الإدخال"` |
| **السطر العلوي الديناميكي** | في الخطأ → رسالة واضحة بالعربية؛ عادي → التعبير الحسابي |
| **حدود الشاشة** | تتحول للون الأحمر `border-semantic-danger/40` عند الخطأ |
| **التوهج الأحمر** | gradient أحمر خفيف يحلّ محل الأزرق عند الخطأ |

### سلوك زر C/AC بعد التحسين:

```
حالة الخطأ (5 ÷ 0 = Error)
  └─ ضغط C  → إعادة ضبط كاملة (INITIAL_STATE) ✅

حالة إدخال (5 + 3_)
  └─ ضغط C  → يمسح "3" → يُعيد "0" (العملية 5+ محفوظة) ✅

حالة انتظار (5 + |)
  └─ ضغط C  → لا فعل (لا يوجد إدخال لمسحه) ✅

Escape (لوحة المفاتيح) → AC دائماً
Delete (لوحة المفاتيح) → C (clearEntry)
```
